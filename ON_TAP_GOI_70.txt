* CONG THUC CHUNG:
--------------------------------------------------
- Thao tac tren Hoa don (Lap HD hoac Huy HD) thi 2 dong cuoi BAT BUOC cap nhat so ghe chuyen bay:
  cb.setSoVeDaBan(...)
  cb.setSoVeConLai(cb.getTongSoVeMoBan() - cb.getSoVeDaBan())
- Ban ve (Lap HD) : CONG so ve da ban (+ sl)
- Huy ve (Huy HD) : TRU so ve da ban (- soVeHuy)
--------------------------------------------------

* CODE DAY DU CAC HAM:

8. Ham Lap hoa don (lapHoaDon):
public boolean lapHoaDon(String maHD, String maKH, String maNV, ChuyenBay cb, int sl) {
    if (cb == null || cb.getSoVeConLai() < sl || timHoaDon(maHD) != null) return false;
    double tien = cb.getGiaVeCoBan() * sl;
    themHoaDon(new HoaDon(maHD, maKH, maNV, cb.getMaCB(), LocalDateTime.now(), sl, tien, "TIEN_MAT", "HIEU_LUC"));
    cb.setSoVeDaBan(cb.getSoVeDaBan() + sl);                     // CONG VE BAN
    cb.setSoVeConLai(cb.getTongSoVeMoBan() - cb.getSoVeDaBan()); // Tinh lai ve con
    return true;
}

9. Ham Huy hoa don (huyHoaDon):
public boolean huyHoaDon(String maHD, ChuyenBay cb) {
    HoaDon hd = timHoaDon(maHD);
    if (hd == null || !"HIEU_LUC".equalsIgnoreCase(hd.getTrangThai())) return false;
    hd.setTrangThai("DA_HUY");
    if (cb != null) {
        cb.setSoVeDaBan(cb.getSoVeDaBan() - hd.getSoLuongVe());  // TRU VE BAN (hoan ve)
        cb.setSoVeConLai(cb.getTongSoVeMoBan() - cb.getSoVeDaBan()); // Tinh lai ve con
    }
    return true;
}

* GIAI THICH LOGIC & TIPS HOC THUOC:
- Buoc 1: Kiem tra if (dieu kien sai hoac null) -> return false.
- Buoc 2: Xu ly hoa don (Lap: themHoaDon; Huy: hd.setTrangThai("DA_HUY")).
- Buoc 3: Cap nhat so ghe (Lap thi + sl, Huy thi - soLuongVe). 2 dong cuoi cung giong het nhau!

15. Chong trung lich bay (QuanLyChuyenBay.java):
// Logic: startMoi < endCu && startCu < endMoi
public boolean kiemTraTrungLich(String maMB, LocalDateTime startMoi, LocalDateTime endMoi) {
    for (ChuyenBay cb : danhSachChuyenBay) {
        if (cb.getMaMayBay().equalsIgnoreCase(maMB) && !"HUY".equalsIgnoreCase(cb.getTrangThai())) {
            LocalDateTime start = LocalDateTime.of(cb.getNgayDi(), cb.getGioDi());
            LocalDateTime end = LocalDateTime.of(cb.getNgayDen(), cb.getGioDen());
            if (startMoi.isBefore(end) && start.isBefore(endMoi)) return true;
        }
    }
    return false;
}
